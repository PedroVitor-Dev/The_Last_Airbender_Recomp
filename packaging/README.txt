Avatar: The Last Airbender Recomp v{VERSION}
============================================

A native PC version of Avatar: The Last Airbender for the Game Boy Advance,
built by static recompilation. https://github.com/PedroVitor-Dev/The_Last_Airbender_Recomp

THIS PACKAGE DOES NOT INCLUDE THE GAME. You need your own ROM dump of the
USA cartridge (game code BQZE, SHA-1 9d864e9b3ccce4e5e1b1c566afa0d06088e88dfd).


HOW TO PLAY
-----------
1. Copy your ROM (.gba) into the "roms" folder next to AvatarRecomp.exe.
2. Run AvatarRecomp.exe.

You can also drag the ROM onto AvatarRecomp.exe, or just run it and pick the
ROM in the window that opens. The choice is remembered.

Windows may show a SmartScreen warning because the program is not signed:
click "More info" and then "Run anyway".

Requirements: Windows 10 or 11 (64-bit).


CONTROLS
--------
GBA              Keyboard            Gamepad (Xbox, 8BitDo in X mode...)
D-pad            Arrow keys          D-pad or left stick
A / B            X / Z               A / B (and X)
L / R            A / S               LB, LT / RB, RT
Start / Select   Enter / Backspace   Start / Back

Settings screen: Esc, F1, the Xbox/home button or Back+Start.
The game freezes while it is open. Everything can be remapped there.

F5 / F9      save / load state        F6 / F7   previous / next slot
Tab (hold)   turbo                    P         pause
F11          fullscreen               F12       screenshot


FILES
-----
tlagba.ini            your settings (next to the executable)
roms\<rom>.sav        the in-game save
roms\states\          save states
roms\screenshots\     screenshots
(saves, states and screenshots are stored next to your ROM)
